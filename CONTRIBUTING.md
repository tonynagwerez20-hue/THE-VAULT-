# Contributing to the Vault

Use a topic branch and open a pull request into `main`. Keep changes narrow and explain the affected authority boundary.

For AMIGO changes, include:

- files changed and why;
- compile/test commands and results;
- whether evidence is native MT5 or offline;
- data period, costs, and trade count for quantitative claims;
- any migration or account-state implications.

Do not commit credentials, broker tokens, private account data, or large raw tick archives.
